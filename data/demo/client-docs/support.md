# Служба поддержки

## Время работы

Операторы отвечают с понедельника по пятницу с 09:00 до 18:00 по московскому времени. В выходные доступна только автоматическая обработка обращений.

## Каналы связи

Обращение можно отправить через форму в личном кабинете или по адресу support@example.invalid. Демонстрационный адрес не принимает реальную почту.
