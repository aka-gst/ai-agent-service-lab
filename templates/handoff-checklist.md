# Чек-лист передачи

- [ ] Репозиторий или архив исходников передан клиенту.
- [ ] Версии Ollama, моделей, Docker и Python записаны.
- [ ] Модели скачаны на целевой компьютер.
- [ ] `.env` создан локально и не добавлен в Git.
- [ ] RAG-индекс построен из согласованных документов.
- [ ] Все тесты и evaluation пройдены.
- [ ] Клиент умеет запустить, проверить и остановить сервис.
- [ ] Клиент знает, где находятся логи и приватные данные.
- [ ] Создан backup; восстановление проверено отдельно.
- [ ] Ограничения и известные ошибки объяснены.
- [ ] Срок и канал поддержки согласованы.
